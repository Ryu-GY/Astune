# Astune 위치 데이터

`cities.json`은 Next.js와 FastAPI가 같이 읽는 도시 사전입니다. 서울, 부산, 인천, 대구, 대전, 광주, 울산, 제주와 도쿄·뉴욕·런던·파리·시드니를 포함합니다. 제주의 기존 좌표와 이름은 유지했습니다. 도시 대표 좌표이므로 정확한 출생 위치는 지도로 선택하거나 직접 입력하세요. 데이터 변경 후 Python 서버를 재시작해야 캐시가 갱신됩니다.

좌표에서 시간대를 찾는 과정은 로컬 timezonefinder 데이터를 사용합니다. 유효한 IANA 시간대를 직접 지정하면 우선 적용합니다. 바다는 임의의 시간대를 선택하지 않습니다. 경계 데이터는 현대 기준이며 역사적 행정 경계 변동을 복원하지 않습니다. zoneinfo는 해당 지역의 출생일 당시 오프셋을 적용합니다.

## 선택적 외부 도시 검색

기본 공급자는 [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)입니다. [무료 서비스 약관](https://open-meteo.com/en/terms)은 비상업 이용과 일 10,000회·시간 5,000회·분 600회 미만을 요구합니다. GeoNames 기반 데이터는 CC BY 4.0 출처 표기가 필요합니다. 상업 서비스에서는 적합한 공급 계약이나 자체 데이터를 준비하세요.

백엔드의 `GEOCODER_ENABLED=true`와 명시적 POST의 `allow_external=true`가 모두 있어야 외부 검색을 실행합니다. 지도 좌표의 시간대 추론은 외부 지오코딩을 사용하지 않습니다. GET 검색이나 타이핑만으로 외부 호출이 발생하지 않습니다. 외부에는 검색어·국가만 보내며 출생 날짜·시간·이름은 보내지 않습니다.

외부 요청은 프로세스별 1초 간격·최근 24시간 최대 9,500회로 제한합니다. 조회 결과는 TTL/LRU 캐시에 보관하고 오류는 캐시하지 않습니다. 자동 재시도는 없습니다. 이 한도는 여러 워커·인스턴스·재시작에 걸쳐 공유되지 않습니다. 무료 공급자를 활성화하는 구성은 단일 워커 개발용이며, 운영 확장 시 공유 제한기나 프록시를 먼저 구성해야 합니다. 실패 시 좌표·시간대를 수동 입력할 수 있습니다. 응답의 `attribution`을 외부 검색 결과와 함께 표시하세요.

## 지도

지도 입력은 Leaflet 1.9.4와 OpenStreetMap 표준 타일을 사용합니다. 위치 클릭·마커 드래그·키보드 이동 후 중심 선택으로 좌표 쌍을 함께 입력합니다. 선택 시 이전 시간대를 지우고 해당 좌표의 시간대를 다시 확인합니다. 응답 순서가 뒤바뀌면 마지막 선택만 반영합니다.

[OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/)에 따라 출처를 지도에 표시하고 브라우저의 기본 Referer와 HTTP 캐시를 유지합니다. 오프라인 다운로드·대량 미리 받기는 제공하지 않습니다. 현재 보는 지도 영역에 대해서만 타일을 요청합니다. `NEXT_PUBLIC_MAP_TILE_URL`로 OSM 출처 표기가 호환되는 별도 공급자로 바꿀 수 있습니다. 변경 시 해당 공급자의 이용 조건과 출처도 확인하세요.
