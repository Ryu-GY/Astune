# Astune 위치 데이터

`cities.json`은 FastAPI가 읽는 기본 도시 사전입니다. 서울, 부산, 인천, 대구, 대전, 광주, 울산, 제주와 도쿄·뉴욕·런던·파리·시드니를 포함합니다. 별 찾기와 계정 화면은 나라·도시 검색으로 출생지를 선택하며, 선택한 후보의 위도·경도와 IANA 시간대를 함께 적용합니다. 지도나 좌표 직접 입력은 기본 화면에서 사용하지 않습니다. 데이터 변경 후 Python 서버를 재시작해야 캐시가 갱신됩니다.

좌표에서 시간대를 찾는 과정은 로컬 timezonefinder 데이터를 사용합니다. 유효한 IANA 시간대를 직접 지정하면 우선 적용합니다. 바다는 임의의 시간대를 선택하지 않습니다. 경계 데이터는 현대 기준이며 역사적 행정 경계 변동을 복원하지 않습니다. zoneinfo는 해당 지역의 출생일 당시 오프셋을 적용합니다.

## 나라와 도시 검색

기본 공급자는 [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)입니다. [무료 서비스 약관](https://open-meteo.com/en/terms)은 비상업 이용과 일 10,000회·시간 5,000회·분 600회 미만을 요구합니다. GeoNames 기반 데이터는 CC BY 4.0 출처 표기가 필요합니다. 상업 서비스에서는 적합한 공급 계약이나 자체 데이터를 준비하세요.

백엔드의 `GEOCODER_ENABLED` 기본값은 `true`입니다. 명시적 POST의 `allow_external=true`가 함께 있어야 사전에 없는 도시를 외부에서 검색합니다. 나라 이름은 한글·영문·국가 코드로 입력할 수 있으며, API에는 ISO 국가 코드와 도시 검색어를 보냅니다. 한국어 결과를 요청하고 같은 이름의 도시는 지역·나라·시간대로 구분합니다. 공급자에서 두 글자는 정확한 이름만 일치하므로 `수원시`처럼 시·군 이름까지 입력하면 도움이 됩니다. GET 검색이나 타이핑만으로 외부 호출이 발생하지 않습니다. 출생 날짜·시간·사용자 이름은 공급자에 보내지 않습니다. 오프라인 운영은 `GEOCODER_ENABLED=false`로 제한할 수 있습니다.

외부 요청은 프로세스별 1초 간격·최근 24시간 최대 9,500회로 제한합니다. 조회 결과는 TTL/LRU 캐시에 보관하고 오류는 캐시하지 않습니다. 자동 재시도는 없습니다. 이 한도는 여러 워커·인스턴스·재시작에 걸쳐 공유되지 않습니다. 무료 공급자를 활성화하는 구성은 단일 워커 개발용이며, 운영 확장 시 공유 제한기나 프록시를 먼저 구성해야 합니다. 검색 실패 시 재시도 안내를 표시하며, 입력을 수정하면 이전 좌표 선택을 해제합니다. 외부 검색 결과에 Open-Meteo / GeoNames 출처를 표시합니다.

## 기존 지도 컴포넌트

기존 지도 컴포넌트는 현재 출생지 입력 화면에서 로드하지 않습니다.

지도 입력은 Leaflet 1.9.4와 OpenStreetMap 표준 타일을 사용합니다. 위치 클릭·마커 드래그·키보드 이동 후 중심 선택으로 좌표 쌍을 함께 입력합니다. 선택 시 이전 시간대를 지우고 해당 좌표의 시간대를 다시 확인합니다. 응답 순서가 뒤바뀌면 마지막 선택만 반영합니다.

[OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/)에 따라 출처를 지도에 표시하고 브라우저의 기본 Referer와 HTTP 캐시를 유지합니다. 오프라인 다운로드·대량 미리 받기는 제공하지 않습니다. 현재 보는 지도 영역에 대해서만 타일을 요청합니다. `NEXT_PUBLIC_MAP_TILE_URL`로 OSM 출처 표기가 호환되는 별도 공급자로 바꿀 수 있습니다. 변경 시 해당 공급자의 이용 조건과 출처도 확인하세요.
