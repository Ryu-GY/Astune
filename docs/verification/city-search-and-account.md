# 도시 검색과 내 정보 검증

2026-10-13. 동시 진행 중인 리딩 UI/해석 변경과 분리하기 위해 커밋 `24e1611`에 이 기능의 변경 파일을 적용한 격리 복사본에서 검증했습니다. 운영 계정·DB는 사용하지 않았습니다.

## 확인한 흐름

- 나라 `일본`, 도시 `오사카` 검색 → 실제 위치 API의 오사카 시 선택 → 좌표와 `Asia/Tokyo` 자동 적용 → 실제 Skyfield 계산으로 Elnath 리딩 생성.
- 합성 테스트 계정으로 로그인 상태를 구성하고 실제 Better Auth 세션 검증을 통과 → 헤더 `로그아웃 · 내 정보` 표시.
- 내 정보에서 `1995-05-05T15:00:30`, 오사카 출생 정보를 저장 → 목록에 표시 → ‘이 정보로 별 찾기’로 이동 → 초 단위 시각과 위치 자동 입력 → 실제 별 계산 성공.
- 리딩 저장 → 내 리딩에 리딩 목록만 표시. 로그인한 사용자 이름, Google 안내, 본문 로그아웃, 출생 프로필 목록은 표시하지 않음.
- 헤더 로그아웃 → 비로그인 상태와 로그인 링크로 전환, 선택했던 프로필이 없는 새 별 찾기 화면 표시.
- 새 프로덕션 페이지에서 `로그인 · 내 정보`와 나라 목록을 확인. 브라우저 오류·경고 없음.

## 자동 검증

- TypeScript 전체 테스트: 51개 통과.
- Python 전체 테스트: 124개 통과.
- TypeScript 타입 검사 및 프로덕션 빌드 통과.
- 권한 통합 테스트: 출생 정보만 저장해도 리딩은 생성되지 않음. 저장한 좌표·시간대·초 단위 시각을 정확히 반환. 다른 사용자와 관리자 모두 타인 프로필 조회 시 404, 비로그인 401.
- 위치 테스트: 같은 도시 이름의 지역 구분과 요청 국가 필터 유지.

나라 표기는 서버와 브라우저의 ICU 버전에 의존하지 않도록 동일한 정적 목록을 사용합니다. 실제 Google OAuth 로그인 화면은 이번 검증 대상에 포함하지 않았으며, 로그인 이후 흐름은 격리 DB의 합성 세션으로 검증했습니다.
