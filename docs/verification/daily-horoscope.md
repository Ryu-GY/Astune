# 오늘의 운세

2026-10-13. 저장한 생년월일 또는 직접 입력한 생일 → 별자리 판별 API → 한국 시간 기준 오늘의 운세 → 화면 표시를 검증했습니다.

## 기능과 기준

- 상단 및 모바일 메뉴에 ‘오늘의 운세’(`/horoscope`) 추가.
- 로그인 시 가장 최근 저장한 출생 정보를 자동 적용. 여러 프로필 중 다른 항목을 불러오거나 생일을 직접 수정 가능. 늦게 도착한 자동 불러오기 응답은 사용자가 편집한 생일을 덮어쓰지 않음.
- 비로그인 사용자도 양력 생년월일만으로 이용 가능. 출생 시간·도시는 필요하지 않음.
- 종합, 연애·관계, 일·공부, 금전·소비, 작은 실천, 행운의 색·숫자 제공.
- 고정 생일 범위의 서양 12별자리 사용. 경계일의 실제 태양 진입 시각을 계산하지 않으며, ‘별 찾기’의 대표 별 계산과 별개임.
- 자체 작성한 상징적 문구를 날짜와 별자리에 따라 조합. 외부 운세 피드, LLM, 유료 API를 호출하지 않음. 생일을 DB에 새로 저장하거나 요청 로그에 남기지 않음.
- 동일 별자리와 한국 날짜에는 동일 결과. 한국 시간 자정과 탭 복귀 시 오늘 날짜를 확인하고 갱신. 실패 시 오류를 표시하고 재시도 가능.

별자리 날짜 구분의 참고 자료: [Astrology.com의 생일별 별자리 안내](https://www.astrology.com/article/zodiac-sign-dates/). 경계일 표기는 자료별로 차이가 있어 앱에서는 명시적인 고정 범위를 사용합니다. 염소자리 12월 22일–1월 19일, 물병자리 1월 20일–2월 18일을 포함한 모든 범위를 테스트로 고정했습니다. 운세 문구는 해당 자료에서 가져오지 않았습니다.

## 검증

- 격리 복사본의 TypeScript 전체 테스트 55개 통과. 최종 프로덕션 빌드 및 타입 검사 통과.
- 12별자리 시작·끝 날짜, 1월 1일·12월 31일, 윤년 2월 29일 판별 통과.
- 한국 시간 자정 직전·직후 날짜 및 내용 갱신, 같은 날 결과의 일관성 통과.
- 존재하지 않는 날짜, 미래 생일, 잘못된 JSON, 추가 필드 거부 및 공개 응답 계약 검증 통과.
- 프로덕션 브라우저에서 합성 계정의 저장 정보 `1995-05-05`가 자동으로 적용되어 황소자리 운세 표시.
- 생일을 `2000-02-29`로 수정해 물고기자리로 변경. 로그아웃 후 프로필·생일이 비워지고 게스트 입력 `1995-12-25`로 염소자리 운세 표시.
- 모바일 390×844 화면에서 네 개 메뉴와 현재 탭 표시 확인. 문서 너비와 콘텐츠 너비가 같아 가로 넘침 없음.
- 브라우저 오류·경고 없음. [데스크톱 화면](screenshots/daily-horoscope-desktop.png), [모바일 화면](screenshots/daily-horoscope-mobile.png).

기존 리딩의 해석·UI를 다른 작업에서 변경하고 있어, `24e1611` 기준의 앞선 도시 검색·내 정보 검증 복사본에 이번 변경을 적용하여 빌드 및 회귀 검증했습니다. 실제 Google OAuth는 수행하지 않고 격리 SQLite DB의 합성 사용자와 실제 Better Auth 세션 검증을 사용했습니다.
