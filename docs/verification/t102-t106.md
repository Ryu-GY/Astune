- T102: DE421 로컬 준비·검사 명령, 서버 시작 시 파일 무결성 및 사용 가능 범위 검사, 예열, `/ready`. DE421의 TDB 범위 1899-07-29~2053-10-09.
- T103: 공용 도시 사전, 좌표→육지 시간대, 수동 보정, 선택적 외부 검색, 중복 도시 선택, TTL/LRU와 외부 호출 제한. 서울·6개 광역시·제주 포함.
- T104: UTC 변환, DST 누락·중복, 30분 전환, 날짜 건너뜀, 과거 한국 DST 테스트.
- T105: apparent alt/az와 밝기·지평선 조건, 일관된 동률 처리. 배열 계산을 독립적인 단일 별 계산과 비교.
- T106: 별 배열·천체력·성표 재사용, 예열 뒤 반복 I/O 없음, 4개 동시 계산 결과 일치, 실제 HTTP P95 기준 통과.

## 성능

최대 등급 5.5 / 성표 2,848개. 날짜·시간·좌표를 바꾼 합성 입력으로 각 경로·동시성마다 100회, 합계 400회 측정했습니다. 각 경로의 첫 요청과 예열 6회는 측정에서 분리했으며 출생 입력별 결과 캐시는 사용하지 않습니다. P95는 nearest-rank 방식입니다. 시작·예열·외부 지오코딩 시간은 포함하지 않습니다.

| 경로 | 동시 요청 | P50 | P95 | 최대 | 오류 |
| --- | ---: | ---: | ---: | ---: | ---: |
| FastAPI | 1 | 12.12ms | 14.83ms | 18.65ms | 0 |
| FastAPI | 4 | 46.77ms | 68.87ms | 90.05ms | 0 |
| Next.js → FastAPI → 해석 | 1 | 28.51ms | 33.14ms | 49.16ms | 0 |
| Next.js → FastAPI → 해석 | 4 | 62.15ms | 74.87ms | 92.01ms | 0 |

전체 미리보기 P95 목표 2,500ms 미만을 충족합니다. 이미 시작된 개발 환경 측정이며 운영 배포의 네트워크·CPU·워커·콜드 스타트 성능을 보장하지 않습니다. 측정 뒤 별도로 진행되는 해석 엔진 변경은 이 수치에 포함되지 않습니다.

실제 API에서 서울 로컬 검색, 뉴욕 좌표→America/New_York, 태평양 좌표의 수동 시간대 요구(422), `/ready` 응답을 확인했습니다. 임시 설정으로 공개 도시 Berlin을 외부 검색해 Europe/Berlin과 반복 조회 캐시 적중을 확인했으며 기본 외부 검색 설정은 꺼 둡니다.
