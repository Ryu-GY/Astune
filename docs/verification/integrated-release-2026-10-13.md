# 도시·계정·운세·개별 별 해설 통합 검증

2026-10-13. 별자리 일러스트 배포 버전 `952018e`에 남은 기능을 합쳐 독립된 작업 폴더에서 확인했다.

- TypeScript 단위·권한·저장 통합 테스트 65개 통과, Python 테스트 124개 통과.
- Next.js 운영 빌드 및 TypeScript 검사 통과. 기존 개발 서버의 Prisma 클라이언트와 분리해 파일 잠금을 피했다.
- 서울 검색 → 좌표·시간대 적용 → 실제 Skyfield 계산 → HIP 28360의 개별 해설, 마차부자리 일러스트, 같은 시각·좌표의 Stellarium 링크 확인.
- 도시 검색에 지도·직접 좌표 입력을 복구했다. 지도 중심 선택으로 위도·경도와 `Asia/Seoul`이 함께 입력되고 실제 리딩이 생성됐다.
- 위치 검색과 지도 시간대 조회의 브라우저 제한을 130초로 맞춰 운영 계산 서버의 120초 기동 대기를 지원한다.
- 2000-02-29 게스트 입력으로 물고기자리와 한국 날짜 2026-10-13의 운세 표시 확인.
- 저장 프로필 접근은 본인만 허용하며 타 사용자·관리자의 접근 거부, 출생 정보만 저장하는 흐름, 기존 리딩 스냅샷 불변성은 통합 테스트로 확인했다.

## 배포 항목

웹은 Vercel 수동 배포, 계산 서버는 Render의 자동 배포 Off를 유지한다. 국가별 외부 도시 검색에는 Render의 `GEOCODER_ENABLED=true`가 필요하다.

운영의 `ASTUNE_RULE_SOURCE=database` 때문에 코드 배포만으로 새 해설이 활성화되지 않는다. 기존 `2026Q4_v2` 규칙을 백업하고 검증한 `2026Q4_v3`의 공통 안내 1개·개별 별 93개 규칙을 트랜잭션으로 게시한다. 기존 게시 버전은 보관하며 저장된 리딩 스냅샷을 수정하지 않는다. DB 스키마 변경은 없다.
